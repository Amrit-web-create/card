# My Card

Pure Kotlin + Jetpack Compose Android app. Fully offline.

- Bank cards (credit, debit) with 14 animated 3D designs, free 3D rotation by finger
- ID cards: Aadhaar, PAN, Voter ID, Driving Licence with front and back details and photo
- Password saver with colour per entry
- Photo vault with in-app crop, grid, full screen viewer and its own archive
- Archive for cards, passwords and photos
- PIN needed to edit or delete a card, and to turn the PIN off
- AES-256-GCM encrypted storage, key in Android Keystore
- Themes: System, Light, Cream, Dark, Black, plus accent colours

## Build on GitHub
1. Upload all files of this folder to a GitHub repo (branch main).
2. Open the Actions tab, run "Build My Card".
3. Download APK / AAB from the run's Artifacts. If it fails, the run Summary lists the errors.
