# My Card

Pure Kotlin + Jetpack Compose Android app. Fully offline.

- 3D flip cards, 5 designs, credit and debit, multiple cards
- Password saver with colour per entry
- AES-256-GCM encrypted vault, key in Android Keystore
- Light / dark / system theme, accent colours, optional PIN lock

## Build on GitHub
1. Upload all files of this folder to a GitHub repo (branch main).
2. Open the Actions tab, run "Build My Card".
3. Download APK / AAB from the run's Artifacts. If it fails, the Summary tab lists the errors.
